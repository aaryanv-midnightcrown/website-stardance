Wearable Bow Motion Sensing

Designing a low-profile, detachable motion-sensing clip using an ESP32-C3 SuperMini and 6-DOF IMU to track real-time bowing gestures and technique.

  • MCU: ESP32-C3 SuperMini (RISC-V)
  • Sensors: 6-DOF IMU (Accelerometer + Gyroscope)
  • Mounting: Custom non-destructive clip design
  • Sampling Rate: 100Hz Sensor Polling
  • Filtering: Complementary filter for inclination estimation
  • Telemetry: Low-latency BLE packet streaming
